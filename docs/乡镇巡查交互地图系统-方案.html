1. 项目概述

建设一套面向乡镇尺度的交互地图系统：在固定巡查点位上持续录入每日测量数据， 支持手机端现场录入与 Excel 批量导入，并在地图与图表中查看任意时间跨度的历史变化； 网页端按权限使用，另设后台对上传数据进行审核、编辑、统计与导出。数据可持续累积，不设入库上限。

典型工作日：巡查员带着手机到点位 → 打开地图定位到固定点 → 填入当日测量值（可附照片/备注）→ 提交入库；管理人员在网页端查看全镇态势、单点历史折线/柱状图，并在后台清理与导出数据。

3. 目标与边界

目标（必须做到）

  • 镇域底图 + 固定点位图层，手机/网页均可加载
  • 按点位持续写入时间序列测量数据（日更为主）
  • 手机端键入；Excel 模板导入；无条目数量硬上限
  • 单点/多点历史折线图、条形图；按日期范围筛选
  • 角色权限（录入 / 查看 / 管理）
  • 后台：列表、编辑、统计、下载（Excel/CSV）

非目标（本期不做）

  • 不做成省级/市级超大屏指挥调度平台
  • 不做复杂工作流审批引擎（可用简单「待审核」状态）
  • 不做原生 App 双端商店上架（优先 PWA / 响应式 H5）
  • 不做离线卫星影像私有化切片（可用在线底图 + 可选缓存）
  • 不强制实时推送；以主动刷新/短轮询即可
技术默认（我方建议，可改）： 前端 Vue3 + Leaflet；后端 FastAPI（Python）；数据库 PostgreSQL + PostGIS； 手机端以同一套 Web 的移动布局 / PWA 交付；底图优先天地图或高德（需 Key）。

4. 角色与权限

角色 手机端 网页地图/图表 后台管理
巡查员 看地图与点位；对本责任点录入/改当日草稿 可看自己提交的数据与趋势 无
业务查看 只读地图与图表 全镇点位只读；图表只读 无
业务管理员 可选 全权限查看；可纠正数据 数据列表、编辑、统计、导出；点位维护
系统管理员 — 全部 用户账号、角色、指标模板、系统配置

权限建议采用 RBAC：用户 → 角色 → 权限码；点位可再挂「责任人/责任组」做行级过滤。

5. 核心业务场景

5.1 日常巡查录入（主路径）

打开手机地图 → 点选固定点位 → 填写当日指标 → 可选拍照 → 提交 → 写入时间序列

5.2 Excel 批量补录

下载模板 → 按点位编码填表 → 上传校验 → 预览错误行 → 确认入库

5.3 历史规律查看

  • 地图点击点位 → 侧栏/弹窗展示近期数值卡片
  • 进入详情：折线（趋势）、柱状（按日/周对比）
  • 支持自定义起止日期、指标切换、多指标叠加（第二期可选）

5.4 后台治理

  • 按日期、点位、录入人、指标筛选
  • 单条编辑 / 作废（软删除，保留审计）
  • 汇总统计（今日完成率、缺报点位、异常阈值）
  • 批量导出 Excel/CSV

7. 技术选型建议

层级推荐理由
地图引擎 Leaflet（或 MapLibre GL） 镇级点位轻量足够；生态成熟；移动端友好
底图 天地图矢量/影像 或 高德 国内合规与标注清晰；需申请 Key
前端 Vue 3 + Vite + ECharts 图表与后台表格开发效率高；PWA 易做
后端 FastAPI + SQLAlchemy/SQLModel Excel 处理、时序查询、类型提示顺手
数据库 PostgreSQL 16 + PostGIS 空间索引 + 时序无限增长；可分区
鉴权 JWT + Refresh；可选短信/账号密码 手机网页登录简单可靠
部署 Docker Compose（Nginx + API + PG） 镇级私有化一台服务器即可
若团队更熟 Node：可用 NestJS + Prisma 等价替换后端；数据库仍建议 PostgreSQL，不要用「仅本地 JSON」作为生产库。

8. 数据模型（核心）

8.1 实体关系（逻辑）

  • 站点 Site / 点位 Point：编码、名称、经纬度、类型、状态、责任人
  • 指标 Metric：编码、名称、单位、数据类型、合理上下限（告警用，不是入库上限）
  • 观测 Observation：点位 + 指标 + 观测时间 + 数值 + 录入人 + 来源（手机/Excel/网页）+ 备注 + 附件
  • 用户 / 角色 / 点位授权
  • 导入任务 ImportJob：文件、校验报告、成功/失败行数

8.2 观测表设计要点（支撑「不断录入、无上限」）

字段说明
id雪花 ID / UUID
point_id固定点位外键
metric_code指标编码
observed_at业务观测时间（可与提交时间不同）
value_num / value_text数值或文本（按指标类型）
sourcemobile | excel | web
created_by录入用户
statusnormal | void（软删）
unique建议：(point_id, metric_code, observed_at::date) 唯一，同日覆盖或版本化二选一

无入库上限策略：观测表按月或按年做 PostgreSQL 分区；索引 (point_id, metric_code, observed_at)；附件走对象存储，库内只存 URL。 「合理阈值告警」与「能否入库」分离——超阈值可入库但标红。

8.3 同日重复策略（需产品确认，默认如下）

默认：同一点位同一指标同一自然日，后提交覆盖前一条，并写审计日志（旧值可追溯）。 若业务需要「一日多次」，改为允许同日多条，图表按时间戳绘制。

9. 手机端设计

必须能力

  • 加载镇域底图与全部固定点位
  • GPS 定位辅助找点（可手动选点，不强制贴合 GPS）
  • 点位列表搜索（名称/编码）
  • 表单：日期默认今天、指标字段、备注、拍照压缩上传
  • 弱网：本地草稿队列，恢复后重试提交
  • 今日已录/未录状态色标

交互建议

  • 首屏即地图，底部「今日任务」抽屉
  • 点选点位 → 半屏录入表单
  • 提交成功后地图上该点变「已录」
  • 可从点位进入「近 7/30 日迷你折线」只读

交付形态：响应式 Web + 可「添加到主屏幕」的 PWA；HTTPS 部署后方可稳定使用定位与相机。

10. 网页端（业务可视化）

  • 地图主视图：固定点位；按最新值或告警状态着色；图例
  • 点位详情面板：基础信息、最新观测、历史图表切换
  • 时间控件：快捷 7/30/90 天 + 自定义区间
  • 图层控制：点位类型开关；影像/矢量底图切换
  • 权限：无管理权用户隐藏「编辑/导入/后台」入口

镇级尺度初始视野建议配置为镇界中心点 + 固定 zoom；可选上传镇界 GeoJSON 做掩膜高亮。

11. 后端管理页面

模块功能
数据台账 观测记录分页、筛选、单条编辑、作废、批量导出
点位管理 新增/停用点位、坐标微调、责任人分配、批量导入点位
指标字典 指标增删改、单位、阈值、排序、是否必填
导入中心 模板下载、上传、校验报告、失败行下载
统计看板 今日录入率、连续缺报、超阈值次数、人员工作量
用户权限 账号、角色、重置密码、停用
审计日志 谁在何时改了哪条观测（满足事后追责）

12. 可视化方案

折线图

单点单指标随时间变化；支持缺测空隙断开或插值开关（默认断开）。适合看趋势与季节性。

条形/柱状图

按日对比、按周汇总均值/最大/最小；多点同一日横向对比（管理端常用）。

  • 图表库：ECharts（导出 PNG 方便做汇报）
  • 大数据量：服务端按间隔降采样（如超过 2000 点自动日聚合），原始数据仍可导出全量
  • 地图侧：最新值标签 + 点击联动图表，避免一屏堆太多系列

13. 录入与 Excel 规范

模板列（建议）

点位编码* 观测日期* 指标编码* 数值* 备注 录入人（可选）
XM-T01-003 2026-10-27 WATER_LEVEL 1.25 雨后复测 张三
  • 编码必须与系统点位/指标字典一致；日期格式统一 YYYY-MM-DD
  • 上传先干跑校验：未知编码、空值、非数字、重复行 —— 全部列出后再入库
  • 单次导入建议软限制（如 2 万行/文件）仅为体验与超时防护，可拆文件续传，不是系统总容量上限

14. 容量与扩展预估

量级假设估算
点位 200 个 × 指标 5 个 × 365 天 约 36.5 万条/年 —— PostgreSQL 轻松
点位 1000 × 指标 10 × 5 年 约 1800 万条 —— 分区表 + 索引即可
照片 客户端压缩至 200–500KB；对象存储按年归档

结论：用正规关系库 + 分区，即可满足「不断录入、不设总上限」；瓶颈通常在附件磁盘与备份策略，而非观测行数。

15. 安全与部署

  • 全站 HTTPS；JWT 短时效 + 刷新令牌
  • 接口按角色鉴权；导出操作记审计
  • 上传文件类型白名单与大小限制；图片剥离 EXIF 可选
  • 数据库每日备份；观测表与附件分开备份
  • 内网部署时，底图 Key 与服务域名需能出网或改用离线瓦片
  • 建议配置：4 核 8G 云主机或本地服务器起步，Docker Compose 一键起

16. 分期实施路线

P1

基础闭环（约 3–5 周）

用户登录与角色；点位 CRUD；手机/网页地图展示点位；手机表单录入；观测列表与 Excel 导出；单点折线/柱状图。

P2

生产可用（约 2–3 周）

Excel 导入校验；后台统计看板；软删除与审计；照片上传；缺报提醒；PWA 与弱网草稿。

P3

增强（按需）

阈值告警与色斑图；多指标对比；镇界掩膜；消息通知；数据质量报表；大屏只读只视。

17. 风险、待确认项与决策清单

待你方确认（会影响实现）

  1. 测量指标有哪些？单位与是否允许一日多测？
  2. 固定点位现有清单格式（Excel/SHP/经纬度）？大约多少个？
  3. 部署环境：纯内网还是可访问公网底图？
  4. 登录方式：账号密码是否足够，要不要短信？
  5. 同日重复录入：覆盖还是追加？

主要风险

风险应对
野外弱网导致丢数 本地草稿队列 + 提交回执 + 可补录
Excel 编码不统一 强制模板 + 预校验 + 点位编码主数据
底图 Key / 合规 提前申请天地图或高德企业 Key；备选离线瓦片
坐标与现场不符 后台支持微调；手机端允许搜索选点不盲从 GPS
